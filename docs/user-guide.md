# Using Wplatoon

Wplatoon is a quick way to check Splatoon schedules on a Windows Phone. The home screen is organized as a set of swipeable sections.

## Choose a game and browse schedules

Use the game-switch control on the home screen to move between Splatoon 3 and Splatoon 2. The available sections change with the selected game:

- **Splatoon 3:** Turf War, Anarchy, X Battles, Salmon Run, gear, and Splatfests.
- **Splatoon 2:** Turf War, Ranked, League, and Salmon Run.

Tap a schedule row to open its details. The current rotation has a countdown on the home screen. Tap refresh when you want Wplatoon to try the feeds again.

The gear and Salmon Run information can include shop availability, stages, weapons, and reward gear. Splatfest results and upcoming events depend on what the feed currently provides.

## Reminders

Where an item has a supported upcoming start or end time, its detail screen may offer a reminder. Wplatoon asks before it creates a phone reminder. Windows Phone limits the number of reminders an app can keep; if that limit is reached, the phone reports that it could not add another one.

## Settings

The settings screen lets you select a 12- or 24-hour clock, a Splatfest region, and a language preference. The selected values are saved on the phone. The language control does not by itself guarantee that every screen or server-provided name is translated.

## Wallpapers

The wallpapers screen combines artwork packaged with the app and stage artwork that Wplatoon can find in its saved schedule data. Server artwork may not appear until the related schedules have been loaded at least once. Choose an image and confirm to ask Windows Phone to set it as the lock screen; the phone may ask for permission.

## A note about connections

The schedules come from online services, so a connection is needed to get fresh information. Wplatoon can show valid saved data while offline, but it cannot promise that saved schedules are current. Images may take longer to load than schedule text on older devices.
